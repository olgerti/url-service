# Url-Service

`Url-Service` is a service that allows you to shorten long URLs, making it easier to share links on websites, in chats, and via emails. This service is built with NestJS and uses MySQL as the database.

## Prerequisites

Before running the project, ensure that you have the following installed:

- Node.js (>= 20.x.x)
- Yarn (for package management)
- MySQL database server
